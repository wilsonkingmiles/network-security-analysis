# Nmap Lab Summary

The approved target was analyzed from a Kali Linux virtual machine. The workflow included DNS resolution, organization of scan artifacts, and an Nmap command using default scripts, service/version detection, OS detection, and normal-text output.

Observed results included:
- 80/tcp open for HTTP
- 443/tcp open for SSL/HTTPS
- 998 filtered ports
- no confirmed OS fingerprint

The lab reinforced that port/service discovery is a starting point. Vulnerability claims require validated version information and authorized follow-up testing.
